# Four in a Row (Connect Four)

A two-player Connect Four game built with plain HTML, CSS, and JavaScript — no installs, no dependencies.

## How to run it

1. Unzip the folder.
2. Double-click `index.html` — it opens straight in your browser.

That's it. No server, no npm, nothing to set up.

## How to play

- Red goes first. Click any column to drop a piece.
- Players alternate turns.
- First to connect four in a row — horizontally, vertically, or diagonally — wins.
- Hit "New game" any time to restart.

## Files

- `index.html` — page structure
- `style.css` — styling and animations
- `script.js` — game logic (board state, win detection, turn handling)
